# Source files materialized into the case work dir before each run.
# Format: <dest-name>  <repo-relative-source-path>   (two or more spaces between)
#
# The golden tier keeps no copy of these files: it points at the fixtures the
# Rust unit tests already use, so the two can never drift.
#
# The Rust tests type-check each fixture file as a package of its own, so every
# file gets its own directory here (`<analyzer>/<stem>/`). Two files in one
# directory would merge into one package and redeclare their identifiers.
#
# Not carried here, with the reason each one cannot be gated:
#
#   cgocall/*        `import "C"` needs cgo and a C toolchain in CI.
#   framepointer/*   the analyzer keys off `build.Default.GOARCH`, so the
#                    golden would differ between an arm64 dev machine and an
#                    amd64 runner.
#   inline_exp/*     imports golang.org/x/exp, which would need a second module
#                    and a `replace` directive in the case go.mod.
#   inline_ioutil/*  the message embeds the Go version that declared the callee
#                    ("declared using go1.26.2"), which differs between
#                    golangci-lint's own toolchain and the local one.
#   buildtag/bad.go  two //go:build lines are a load error ("multiple //go:build
#                    comments"), so golangci-lint reports a typecheck failure
#                    and drops every other finding in the run.
#
# composites' fixture imports a sibling package; it is materialized at the path
# its import resolves to.
